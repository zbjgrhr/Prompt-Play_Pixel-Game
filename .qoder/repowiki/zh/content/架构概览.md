## 项目概述

Pixel Seed 是一款基于 AI 生成的 2D 像素风网页游戏，其核心理念是“用一粒 AI 种子，生长无限像素世界”。该项目通过用户输入的主题或提示词，利用大模型生成专属的像素风格角色形象和关卡背景，动态构建可玩的游戏世界。整个系统采用 Next.js 15.5.2 构建，使用 App Router 模式进行路由管理，前端样式基于 Tailwind CSS 实现，状态管理依赖 Zustand 5.0.8。

项目验证了 AI 作为内容引擎的潜力，实现了从“输入一个种子”到“生成一个世界”的闭环流程。用户无需美术基础，仅需选择预设主题（如史诗魔幻、赛博朋克）或输入自定义提示词，即可获得风格一致的像素美术资源并立即进入游戏体验。

## 技术栈与选型

项目的技术栈经过精心选择，以确保开发效率、性能和可维护性。前端框架采用 Next.js 15.5.2，结合 App Router 模式提供现代化的路由解决方案。样式系统使用 Tailwind CSS 4.0，通过实用类（utility classes）实现快速、一致的 UI 开发。状态管理选用轻量高效的 Zustand 5.0.8，避免了 Redux 的复杂性，同时支持中间件和持久化。

UI 组件库采用 Ant Design 5.27.1，提供了丰富的预制组件，加速了界面开发。动画效果由 Framer Motion 12.23.12 驱动，为用户交互提供流畅的视觉反馈。HTTP 客户端使用原生 Fetch API，与 Next.js 的 API Routes 无缝集成。图标库结合了 Ant Design Icons 和 Lucide React，满足不同场景的图标需求。

## 核心架构模式

### 组件化设计

项目采用模块化的组件架构，将 UI 拆分为独立、可复用的组件。核心组件包括 `GameCanvas`（游戏画布）、`SideMenu`（侧边菜单）、`ThemePreview`（主题预览）和 `ThemesList`（主题列表）。这些组件位于 `components/` 目录下，并通过 `components/ui/index.ts` 统一导出，简化了导入路径。

组件设计遵循单一职责原则，例如 `SideMenu` 负责主题选择和创建，`ThemePreview` 展示生成的图像资源。这种设计提高了代码的可维护性和可测试性。

### 集中式状态管理

状态管理是项目的核心，通过 `lib/store.ts` 中的 Zustand store 实现。全局状态包括游戏状态（menu/loading/playing）、选中主题、自定义提示词、角色类型、关卡类型、当前动作、游戏数据、玩家位置等。

Zustand 提供了简洁的 API 来定义状态和更新函数。例如，`setGameState` 用于切换游戏状态，`setPlayerPosition` 更新玩家坐标。状态变更通过 React 的上下文机制自动触发 UI 更新，确保了数据的一致性。

### 配置集中化

配置信息集中管理在 `configs/index.ts` 文件中。该文件导出 `PRESET_THEMES` 数组，包含所有预设主题的配置，如 ID、名称、描述和示例图像 URL。此外，`GAME_TEMPLATES` 对象定义了用于 AI 图像生成的正向和反向提示词模板，确保生成内容符合 2D 像素风游戏的风格要求。

这种集中化配置便于维护和扩展，新增主题或修改提示词只需更新该文件。

## 数据流分析

系统的数据流遵循单向数据流原则：用户交互触发状态变更，状态驱动 UI 更新，并通过 API 路由与后端服务通信。

1. **用户交互**：用户在 `SideMenu` 中选择主题或输入自定义提示词，触发 `handleCreateTheme` 函数。
2. **状态更新**：`handleCreateTheme` 调用 `setLoading(true)` 更新全局状态，显示加载界面。
3. **API 调用**：前端通过 `fetch('/api/generate')` 发送 POST 请求到 `/api/generate/route.ts`。
4. **后端处理**：API 路由接收请求，调用 DashScope 的 Qwen-Image 模型生成角色和背景图像。
5. **响应处理**：生成完成后，后端返回图像 URL，前端更新 `gameData` 状态。
6. **UI 更新**：`GameCanvas` 组件监听 `gameData` 变化，使用新图像渲染游戏世界。

整个流程中，Zustand 确保了状态的同步和一致性，而 Tailwind CSS 和 Framer Motion 则提供了流畅的视觉反馈。

## 前端层

前端层基于 Next.js 15.5.2 构建，采用 App Router 模式。`app/` 目录下的 `page.tsx` 是应用的入口点，使用 `Splitter` 组件将界面分为侧边菜单和主内容区。`SideMenu` 包含 `ProjectHeader`、`ModelSelector`、`ThemeCustomizer` 和 `ActionButtons` 等子组件，提供完整的主题创建和管理功能。

UI 组件使用 Ant Design 实现，如 `Card`、`Button`、`Input` 等，确保了界面的一致性和专业性。Framer Motion 用于实现动画效果，如按钮悬停、元素淡入等。Tailwind CSS 通过实用类快速构建响应式布局，适配不同屏幕尺寸。
